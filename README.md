# Portfolio — Habbessi Fares

Portfolio étudiant responsive en HTML, CSS et JavaScript, prêt à publier avec GitHub Pages.

## Fichiers
- `index.html` : contenu du portfolio
- `style.css` : thème sombre bleu, mise en page responsive et animations CSS
- `script.js` : menu mobile, animations au défilement et année automatique

## À personnaliser avant publication
1. Dans `index.html`, remplace `TON.EMAIL@EXEMPLE.COM` par ton adresse e-mail.
2. Remplace les liens LinkedIn et GitHub par tes profils.
3. Vérifie les compétences dans la section « Compétences » et supprime celles que tu ne maîtrises pas.
4. Les trois projets sont des exemples de présentation, pas des expériences confirmées. Remplace les descriptions par tes projets académiques réels et ajoute les liens vers leurs dépôts.
5. Modifie les informations de formation si nécessaire.

## Tester en local
Ouvre `index.html` dans un navigateur. Pour un meilleur aperçu du développement, utilise l'extension Live Server de Visual Studio Code.

## Publier avec GitHub Pages
1. Crée un dépôt public nommé `portfolio` sur GitHub.
2. Envoie les quatre fichiers (`index.html`, `style.css`, `script.js`, `README.md`) dans le dépôt.
3. Ouvre **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Choisis la branche `main` et le dossier `/(root)`, puis clique sur **Save**.
6. Attends la fin du déploiement. Le site sera normalement accessible à l'adresse `https://TON-USERNAME.github.io/portfolio/`.

## Remarque
La police web utilise Google Fonts ; si les polices ne sont pas accessibles, le site utilisera les polices de secours.
